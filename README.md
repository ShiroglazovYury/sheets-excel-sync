# sheets-excel-sync — данные из Google Sheets в Excel по кнопке

Проект по Python (ИИМУП, НИУ ВШЭ, 2026), тема «Автоматизируй свою рутину».

## Коротко

На работе прогнозы живут в Google Sheets, а управленческая отчётность — в
Excel. Раньше, чтобы обновить Excel, приходилось скачивать Google-таблицу,
искать в ней нужный диапазон среди десятков тысяч строк и вставлять его
руками. На это уходило 20–30 минут, и Excel при этом зависал.

Теперь в Excel есть кнопка. Нажимаешь — и через ~20 секунд данные из
Google-таблицы лежат на нужном листе: уже очищенные и проверенные. Если
данные в источнике сломаны, программа ничего в Excel не трогает и пишет, что
не так.

## Что происходит, когда нажимаешь кнопку

```
Кнопка в Excel
   │   макрос VBA (vba/SheetSync.bas) через надстройку xlwings запускает Python
   ▼
1. Чтение      забираем диапазон из Google-таблицы
2. Очистка     '1 234,56' → число, даты → даты, лишние пробелы → убрать, мусор → пусто
3. Проверки    нет нужного столбца, дубли, мусора слишком много?  → СТОП, Excel не трогаем
4. Сравнение   что изменилось с прошлого раза? если ничего — Excel не трогаем
5. Запись      кладём данные на лист Excel
6. Память      бэкап .xlsx + запись в историю + снимок данных на следующий раз
   ▼
Окно в Excel: сколько строк записано, что изменилось, какие проблемы нашлись
```

Всё это делает один «дирижёр» — `sheetsync/runner.py`. Каждый шаг — отдельный
файл, и `runner.py` просто вызывает их по очереди.

## Что лежит в репозитории

```
sheetsync/            сама программа
tests/                автоматические проверки программы (79 тестов)
vba/SheetSync.bas     макросы для кнопок в Excel
config.example.yaml   шаблон настроек: какую таблицу читать и куда писать
requirements.txt      какие библиотеки нужны
pyproject.toml        настройка для pytest
.gitignore            что не загружать в git (ключ Google, личный конфиг и т.д.)
```

### Файлы программы (`sheetsync/`)

Читать удобнее снизу вверх — от простого к сложному.

| Файл | Что делает простыми словами |
|---|---|
| `errors.py` | Виды ошибок программы. У «ожидаемых» ошибок текст написан для человека — его и видно в окне Excel. |
| `table.py` | Формат таблицы внутри программы: заголовки + строки + номера строк, как в Google Sheets. |
| `config.py` | Читает `config.yaml` и сразу проверяет, что там всё заполнено правильно. |
| `auth.py` | Открывает ключ Google — «пропуск» программы к таблице. |
| `source.py` | **Шаг 1.** Читает диапазон из Google-таблицы. Ошибки Google переводит на понятный язык («нет доступа — добавьте такой-то email»). |
| `cleaning.py` | **Шаг 2.** Чистит каждую ячейку: числа из текста, даты в разных форматах, лишние пробелы, мусор. |
| `validation.py` | **Шаг 3.** Проверяет данные по правилам. Ошибка — стоп, предупреждение — пишем, но сообщаем. |
| `diff.py` | **Шаг 4.** Сравнивает с прошлым разом: сколько строк добавилось, какие ячейки и на сколько изменились. |
| `excel_target.py` | **Шаг 5.** Пишет данные в открытую книгу Excel. |
| `backup.py` | **Шаг 6.** Сохраняет копию записанных данных в папку `backups/`. |
| `state.py` | **Шаг 6.** Память программы: история запусков и снимок данных в базе SQLite. |
| `runner.py` | Дирижёр: вызывает шаги 1–6 по порядку. |
| `excel_entry.py` | То, что вызывает кнопка в Excel. Любой итог превращает в понятное окно. |
| `cli.py`, `__main__.py` | То же самое, но из консоли: `python -m sheetsync ...`. |

У каждой функции в коде есть подробное описание (docstring): что она делает
и зачем нужна.

## Своя логика: что останавливает запись

| Ситуация | Что делает программа |
|---|---|
| Пропал или переименован нужный столбец | **Стоп.** Если есть похожий столбец (например, `Company` вместо `company`), подсказывает |
| Ключ строки (например, номер заказа) повторяется или пустой | **Стоп**, пишет номера строк |
| Строк стало намного меньше, чем в прошлый раз | **Стоп**: похоже, кто-то удалил часть данных. Если так и задумано — запуск с `--force` |
| Слишком много нечитаемых чисел | **Стоп**: похоже, столбцы съехали |
| Отдельная мусорная ячейка (`#REF!`, «уточнить», дата `31.02`) | Пишем пустую ячейку + предупреждение |
| Выручка не равна объём × цена | Предупреждение: скорее всего, выручку поправили руками |
| Данные не изменились с прошлого раза | Excel не трогаем |

Правила и их пороги настраиваются в `config.yaml` для каждого задания.

## Что программа помнит между запусками

| Где | Что там |
|---|---|
| `state/sync_state.sqlite` | История всех запусков и последний записанный срез данных (с ним сравнивается следующий запуск) |
| `backups/` | Копия данных после каждого успешного синка (хранятся последние 10) |
| `reports/` | Полный список найденных проблем в данных (в окне Excel видны только первые 5) |
| Лист `Sync Log` в книге Excel | Журнал синков прямо в Excel |

Эти папки создаются сами и в git не попадают.

## Краевые случаи, которые программа учитывает

**В данных:**
- числа текстом из русской таблицы: `1 234,56`, `1.234,5`, `(150)`, `12%`;
- «нет данных»: `n/a`, `-`, `#N/A` → пустая ячейка, а не ноль;
- мусор в числах: `#REF!`, «уточнить»;
- даты в разных форматах (`2026-03-15`, `15.03.2026`) и невозможные даты (`31.02.2026`);
- лишние пробелы в названиях: `СтальГрад ` и `СтальГрад` иначе посчитались бы
  как две разные компании;
- пустые строки-разделители посреди таблицы;
- дубли ключей, пропавшие столбцы, резкое уменьшение числа строк.

**В Excel:**
- Excel сам превращает `2026-03` в дату, а ИНН `0274…` — в число без нуля →
  такие столбцы получают формат «Текст»;
- через COM Excel понимает коды формата в языке Windows (в русской Windows
  `dd.mm.yyyy` ломается) → форматы дат не задаём, Excel ставит их сам;
- новых строк меньше, чем старых → старая область сначала очищается, чтобы
  снизу не остался хвост;
- Excel пересчитывает формулы после каждого куска записи и виснет → на время
  записи пересчёт выключается;
- книга в папке OneDrive → ищем открытую книгу по имени файла.

**В окружении:**
- нет ключа, ключ битый, таблица не расшарена, нет листа, нет интернета,
  лимиты Google → понятное сообщение вместо ошибки Python;
- непредвиденная ошибка → короткое окно + подробности в `reports/crash_*.txt`.

## Как запустить

Нужны Windows, Excel, Python 3.11+, Google-таблица с данными и книга Excel,
куда их класть.

1. **Библиотеки.**
   ```powershell
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. **Ключ Google.** В Google Cloud Console создать сервисный аккаунт, включить
   Google Sheets API, скачать JSON-ключ и положить его в
   `secrets/service_account.json`. Google-таблицу расшарить на email
   сервисного аккаунта (роли «Читатель» достаточно).
3. **Настройки.** Скопировать `config.example.yaml` в `config.yaml` и вписать
   ссылку на свою таблицу и путь к своей книге Excel.
4. **Проверка.**
   ```powershell
   python -m sheetsync check
   ```
   Покажет `[OK]` или `[!!]` по каждому шагу: конфиг, ключ, таблица, листы, книга.
5. **Кнопки в Excel.**
   - Установить надстройку: открыть Excel и выполнить `xlwings addin install`.
   - На вкладке xlwings заполнить **Interpreter** (`<папка проекта>\.venv\Scripts\python.exe`)
     и **PYTHONPATH** (`<папка проекта>`).
   - В личную книгу макросов (PERSONAL.XLSB) импортировать `xlwings.bas` (лежит
     в `.venv\Lib\site-packages\xlwings\`) и `vba/SheetSync.bas`.
   - Нарисовать в книге кнопки и назначить им макросы `PERSONAL.XLSB!SyncAll`,
     `SyncForecast`, `SyncOrders`.

## Как пользоваться

- **Из Excel:** нажать «Обновить всё» (или кнопку одного задания).
- **Из консоли:**
  ```powershell
  python -m sheetsync run all              # синк всех заданий
  python -m sheetsync run orders --dry-run # только проверить, Excel не трогать
  python -m sheetsync run orders --force   # записать принудительно
  python -m sheetsync history              # история запусков
  python -m sheetsync check                # проверить установку
  ```
- **Тесты:**
  ```powershell
  python -m pytest -q
  ```
  Проверяют очистку, правила, сравнение, историю и весь сценарий целиком — без
  интернета и без Excel (Google и Excel в тестах заменены «поддельными»).

## Как добавить новый диапазон

Код менять не нужно: достаточно добавить новое задание в раздел `jobs` в
`config.yaml` — с какого листа и диапазона брать данные, на какой лист и в
какую ячейку класть, какие столбцы числовые и какие правила проверять. Потом
добавить для него макрос в `SheetSync.bas` и кнопку в Excel.
